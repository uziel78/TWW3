# Faction_Dark_Elves mod history

Dated design and test log for every Dark Elf mod, in the order things happened (2026-11-22 to
2026-11-25). Append new entries at the end with the date, version and "untested"/"confirmed".
Paths: `<GAME>` = game install, `<MASTERS>` = RPFM MyMods folder (Dropbox). Cross-faction engine
lessons are collected in [../../docs/ENGINE_LESSONS.md](../../docs/ENGINE_LESSONS.md).

**Pitfall:** the launcher's "override" checkbox under savegames broke things and caused the crash-on-load during testing. Before blaming a mod for crashes, ask whether that option is on.

**Why:** a long debugging session on 2026-11-22 chased pack-format theories when the real cause was that launcher setting.
**How to apply:** when a TW:WH3 mod crashes on load, check launcher/save settings first, then test on a new campaign with only that mod enabled.
